# Audit relations inter-blocs v0.1

## Objectif

Faire vivre le monde au-delà des opérations du joueur sans transformer Le Grand Alignement en diplomatie détaillée ou en wargame.

## Modèle de relations

Le prototype suit un petit nombre de relations stratégiques entre blocs. Chaque relation possède :

- deux blocs ;
- une tension ;
- une coopération ;
- une dépendance ;
- un domaine ;
- un libellé lisible ;
- une tendance récente.

Les domaines actuels couvrent sécurité, commerce, climat, technologie, information et ressources.

## Dynamique autonome

Après les effets du joueur, le monde avance selon quelques règles déterministes :

- l'escalade globale rigidifie les relations de sécurité ;
- le stress climatique aggrave les relations climat, ressources ou migrations ;
- le soupçon IA tend les relations technologiques ou informationnelles ;
- l'instabilité interne d'un bloc déborde dans ses relations ;
- une forte coopération amortit parfois une tension.

Le système produit au plus quelques signaux par tour pour rester lisible.

## Effets des opérations

Certaines opérations modifient aussi les relations :

- canaux diplomatiques secrets et relais diplomatiques apaisent ;
- défense commune peut tendre les relations de sécurité ;
- campagne d'information peut améliorer la coopération ;
- désinformation contrôlée augmente les tensions informationnelles ;
- conversion écologique crée des frictions de ressources ou de commerce ;
- fiscalité des mégacapitalistes affecte les tensions liées aux plateformes ;
- soutien aux intellectuels critiques peut tendre les relations informationnelles.

## Interface

Une vue Relations liste les relations suivies avec domaine, blocs, tension, coopération, dépendance, tendance et statut.

La carte affiche seulement les trois relations les plus tendues sous forme de lignes. Cette limite protège la lisibilité.

## Rapports de blocs

Le rapport de bloc inclut maintenant les relations extérieures :

- relation la plus tendue ;
- relation la plus coopérative ;
- tendance récente ;
- lecture stratégique.

## Rapport d'évolution

Le rapport d'évolution ajoute :

- dynamique autonome du monde ;
- changements relationnels ;
- plus forte hausse de tension ;
- plus fort apaisement ;
- synthèse courte.

## Événements relationnels

Six événements courts sont liés aux seuils de relations :

- Normes IA incompatibles ;
- Incident interprété ;
- Sommet climatique fracturé ;
- Accord discret ;
- Guerre des plateformes ;
- Forum Sud-Sud.

## Limites

- Les relations ne forment pas une diplomatie complète.
- Il n'y a ni alliances, ni traités détaillés, ni routes, ni fronts.
- Les lignes de carte sont indicatives.
- Les textes restent fonctionnels ; une passe littéraire viendra plus tard.

## Prochaine priorité

Playtest de dix tours en observant si les relations aident à comprendre que le monde évolue par sa propre inertie.
