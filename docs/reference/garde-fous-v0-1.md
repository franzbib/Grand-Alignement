# Garde-fous v0.1

Ces limites protègent Le Grand Alignement contre la dispersion. Elles peuvent évoluer plus tard, mais pas sans décision documentée.

## Interdits actuels

- Pas de Supabase avant prototype convaincant.
- Pas d'authentification.
- Pas d'IA générative en temps réel.
- Pas de multijoueur.
- Pas d'éditeur de scénario maintenant.
- Pas de carte détaillée à 190 États.
- Pas d'unités militaires.
- Pas de sous-systèmes sociaux visibles complexes.
- Pas de sous-systèmes militaires détaillés.
- Pas d'arbre technologique.
- Pas d'économie quantitative exhaustive.
- Pas de refonte graphique tant que la jouabilité n'est pas vérifiée.

## Dérogations possibles

Une dérogation n'est possible que si elle :

- Sert directement la boucle de jeu.
- Peut être testée vite.
- Peut être retirée sans casser le projet.
- Est documentée dans `docs/REPRISE.md` ou dans un futur dossier `docs/decisions`.

## Réflexe attendu

Si une idée paraît séduisante mais non nécessaire, l'archiver dans `docs/idees-mises-de-cote.md` au lieu de l'implémenter immédiatement.
