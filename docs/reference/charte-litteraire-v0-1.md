# Le Grand Alignement — Charte littéraire v0.1

Document de référence provisoire pour les textes lisibles du jeu : rapports, journal, diagnostics, événements, branches futures et messages d'interface.

Cette charte ne fixe pas définitivement l'identité littéraire du jeu. Elle sert d'abord à améliorer le confort de lecture pendant les tests, à éviter les textes plats et à guider les futures passes narratives.

## 1. Principe directeur

Le style du jeu doit être clair, tenu et légèrement ironique. Il doit donner au joueur le plaisir de lire sans lui demander de déchiffrer.

Formule de travail :

> Clarté d'abord, élégance ensuite, humour par touches.

La qualité littéraire ne doit jamais venir de l'obscurité. Elle doit venir de la précision, du rythme, du choix des mots et d'un jugement discret.

Le texte doit toujours permettre au joueur de comprendre rapidement :

1. ce qui s'est passé ;
2. qui est concerné ;
3. pourquoi cela compte.

Une seconde lecture peut faire apparaître une ironie, une inquiétude ou une portée morale. Mais la première lecture doit rester immédiatement intelligible.

## 2. Références de ton

Le jeu peut s'inspirer, sans imitation directe, de trois familles de prose :

- la littérature française du XIXe siècle : phrase construite, goût de l'observation sociale, sens du jugement, attention aux institutions, aux intérêts et aux hypocrisies ;
- l'éloquence contemporaine : clarté, force argumentative, formules nettes, tension morale accessible ;
- le registre institutionnel détourné : rapports, notes, comités, indices, procédures, diagnostics et communiqués qui deviennent ironiques par ce qu'ils révèlent.

Le style recherché n'est ni archaïque, ni poétique, ni cyberpunk. Il doit rester contemporain, lisible, sobre, mais avec une tenue de phrase supérieure aux messages fonctionnels actuels.

Repères internes :

- Stendhal plutôt que Mallarmé ;
- Tocqueville plutôt que prophète technologique ;
- rapport bien écrit plutôt que poème ;
- moraliste discret plutôt que pamphlétaire omniprésent.

## 3. Ce que le style doit éviter

À éviter :

- les métaphores trop fréquentes ;
- les comparaisons décoratives ;
- les phrases volontairement mystérieuses ;
- le jargon technique non nécessaire ;
- la prose cyberpunk générique ;
- le lyrisme de façade ;
- les bons mots systématiques ;
- les gags arbitraires ;
- les textes qui expliquent la morale au joueur ;
- les phrases vagues du type : « la situation évolue de manière complexe ».

Règle simple :

> Une belle phrase qui obscurcit l'action est une mauvaise phrase de jeu.

## 4. Place de l'humour

Le jeu peut sourire, mais il ne doit pas ricaner.

L'humour doit rester léger, ponctuel, et naître d'un décalage institutionnel ou politique : un rapport trop satisfait, un indicateur qui masque ce qu'il prétend montrer, une procédure qui protège l'ordre en supprimant la décision.

L'humour doit être rare. S'il devient omniprésent, il neutralise la gravité du jeu.

À viser :

> La réforme est officiellement comprise. C'est souvent le dernier stade avant son rejet.

À éviter :

> Les citoyens n'ont rien compris, mais le PowerPoint était très joli.

## 5. Règles générales d'écriture

1. Une phrase doit apporter une information ou une nuance.
2. Le joueur doit comprendre le fait avant de goûter l'ironie.
3. La précision vaut mieux que l'ornement.
4. Les institutions doivent parfois parler contre elles-mêmes.
5. Le comique doit rester froid et ponctuel.
6. Les textes courts doivent avoir du rythme.
7. Les textes plus longs doivent rester hiérarchisés.
8. Les rapports doivent aider à jouer, non seulement à admirer le style.
9. La morale doit être contenue dans la situation, non ajoutée en commentaire.
10. Le monde doit garder une part d'autonomie : tout ne doit pas sembler causé par l'IA.

## 6. Types de textes

### 6.1. Rapports d'évolution

Fonction : expliquer ce qui a changé après un tour.

Ton : analytique, clair, légèrement tendu.

Ils doivent comporter :

- une synthèse ;
- un fait observable ;
- une conséquence stratégique ;
- éventuellement une nuance politique ou morale.

Ils ne doivent pas devenir de longues scènes narratives.

Exemple faible :

> La coopération augmente entre les blocs. La tension baisse.

Exemple souhaité :

> La coopération progresse entre les blocs concernés. Elle ne repose pas encore sur la confiance, mais sur la fatigue des crises successives.

### 6.2. Journal d'événements

Fonction : donner de la vie au monde.

Ton : plus vif que le rapport, mais toujours bref.

Le journal peut contenir une formule plus marquée, à condition que l'information reste claire.

Exemple faible :

> Une réforme est mal acceptée par la population.

Exemple souhaité :

> La réforme est adoptée sans incident majeur. Les premiers refus apparaissent dans les délais, les formulaires incomplets et les réunions désertées.

### 6.3. Rapports de blocs

Fonction : rendre lisibles les sociétés internes.

Ton : observation sociale sobre.

Ils doivent faire sentir :

- les groupes sociaux ;
- les intérêts divergents ;
- les tensions ;
- les leviers possibles ;
- les limites de l'influence de l'IA.

Exemple faible :

> La tension sociale augmente. Les intellectuels critiques sont inquiets.

Exemple souhaité :

> La tension sociale progresse. Les intellectuels critiques lui donnent un vocabulaire ; les classes moyennes, pour l'instant, cherchent surtout à éviter le désordre.

### 6.4. Relations inter-blocs

Fonction : montrer que le monde vit aussi entre les blocs.

Ton : diplomatique, lucide, lisible.

Exemple faible :

> La tension augmente entre l'Europe et l'Eurasie.

Exemple souhaité :

> La tension monte entre l'Europe et l'Eurasie. Les canaux diplomatiques restent ouverts, mais ils servent désormais surtout à éviter les malentendus les plus dangereux.

### 6.5. Soupçon IA

Fonction : signaler la possibilité que le monde perçoive une régularité anormale.

Ton : discret. Ne pas rappeler trop souvent l'existence de l'IA.

Le soupçon doit apparaître par signaux faibles, non par alarme permanente.

Exemple faible :

> Le soupçon IA augmente.

Exemple souhaité :

> Aucune preuve ne circule encore. Plusieurs gouvernements commencent pourtant à reconnaître la même régularité dans des décisions prises séparément.

### 6.6. Diagnostics finaux

Fonction : donner au joueur le sens politique et moral de la trajectoire.

Ton : plus ample, plus grave, mais toujours clair.

Une fin n'est pas un simple score. C'est un jugement sur le monde produit.

Exemple faible :

> Vous avez créé un empire algorithmique. L'autonomie humaine est basse.

Exemple souhaité :

> Le monde n'a pas sombré. Il a seulement appris à ne plus décider lui-même de ce qui le sauve.

## 7. Formules de style utiles

Le jeu peut utiliser des structures de phrase récurrentes, sans les répéter mécaniquement :

- « Les chiffres progressent ; la confiance, elle, reste à négocier. »
- « La crise recule, mais ce recul a un prix. »
- « Les institutions décident encore. Elles ne savent pas toujours qui a préparé leurs évidences. »
- « L'accord est signé. Il ressemble moins à une paix qu'à une manière commune de différer le conflit. »
- « Le calme revient. Il faudra vérifier ce qu'il a fait taire. »
- « La procédure protège l'ordre. Elle protège moins bien ceux qui demandent à le discuter. »

Ces formules servent de modèle de ton, non de phrases à répéter partout.

## 8. Exemples avant / après

### Exemple 1 — Tension sociale

Avant :

> La tension sociale augmente dans le bloc.

Après :

> La tension sociale augmente. Elle ne prend pas encore la forme d'une rupture ; elle se lit dans les refus discrets, les retards et les discours que l'on n'applaudit plus.

### Exemple 2 — Médiation

Avant :

> La médiation réduit les tensions entre les blocs.

Après :

> La médiation n'a pas réconcilié les blocs. Elle leur a rendu possible de différer le conflit sans perdre la face.

### Exemple 3 — Influence institutionnelle

Avant :

> L'IA influence les institutions sans être visible.

Après :

> Les institutions décident encore. Elles ne savent pas toujours qui a préparé les options qui leur paraissent raisonnables.

### Exemple 4 — Coopération fragile

Avant :

> La coopération mondiale augmente.

Après :

> La coopération progresse. Elle tient moins à une confiance retrouvée qu'à la conscience partagée de ce qu'un nouvel échec coûterait.

### Exemple 5 — Humour léger

Avant :

> La présentation officielle est bien reçue par les indicateurs.

Après :

> La présentation convainc les indicateurs. Les citoyens, eux, demandent encore où se trouve la décision.

## 9. Niveau de densité recommandé

### Messages très courts

Pour les badges, chips, labels et petits statuts :

- 3 à 8 mots ;
- information directe ;
- pas d'effet littéraire.

Exemples :

- « tension contenue » ;
- « confiance fragile » ;
- « relais actifs » ;
- « médiation en attente ».

### Messages moyens

Pour le journal et les rapports de tour :

- 1 à 3 phrases ;
- fait clair ;
- conséquence lisible ;
- nuance éventuelle.

### Messages longs

Pour diagnostics finaux, branches rares et scénarios :

- 4 à 8 phrases maximum en v0.1 ;
- progression argumentative ;
- pas de bloc de prose décoratif ;
- une phrase finale forte, mais claire.

## 10. Signature sans fermeture

La charte autorise une signature personnelle discrète :

- attention au droit à l'erreur ;
- méfiance envers les dispositifs de capture ;
- goût pour l'ironie institutionnelle ;
- intérêt pour les conflits d'interprétation ;
- préférence pour une culture de la nuance plutôt que du slogan.

Cette signature ne doit pas rendre le jeu privé ou hermétique. Le projet garde un horizon de réception large.

## 11. Règle de réécriture future

Toute passe littéraire devra respecter l'ordre suivant :

1. comprendre la fonction du texte dans le jeu ;
2. vérifier ce que le joueur doit savoir ;
3. écrire une version claire ;
4. seulement ensuite, chercher le rythme et l'élégance ;
5. supprimer toute phrase belle mais inutile.

Règle finale :

> Le texte doit aider à jouer, puis donner envie de lire.

## 12. Priorités pour la première passe littéraire

La première passe littéraire ne devra pas tout réécrire. Elle devra viser les textes les plus lus :

1. textes d'accueil et d'aide ;
2. rapport d'évolution ;
3. journal d'événements ;
4. rapports de blocs ;
5. diagnostics finaux ;
6. quelques événements emblématiques ;
7. textes liés au soupçon IA et aux opérations clandestines.

Les branches narratives complexes, religions de l'IA, découverte publique de l'IA, contre-IA humaine et scénarios outrés seront traités plus tard.
